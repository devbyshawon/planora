# Final screenshot capture guide

Capture your installed/deployed Stage 8 app using a fictional demo account. These screenshots should show your final verified environment for your report. Internal browser-check images are not included in this release.

On your Mac use **Shift+Command+4** for a selected area, or the capture controls in **Shift+Command+5**. Use a consistent window size, hide unrelated tabs, and check every image for personal details before sharing.

| Suggested filename | Capture | Caption |
| --- | --- | --- |
| `01-exact-day.png` | Day view with 09:15–09:55 and an adjacent task | Exact custom-time scheduling without hourly rounding |
| `02-week-month.png` | Weekly or monthly view with mini-month and filters | Multiple calendar views over the same saved plan |
| `03-recurrence.png` | Recurring-task definition with an occurrence exception | Repeat rules and independent occurrence editing |
| `04-bucket-history.png` | Bucket/rescheduling history for a fictional task | Identity and history retained through postponement |
| `05-progress.png` | A populated progress period with category totals | Historical daily outcomes and exact planned/completed minutes |
| `06-downloads.png` | Export preview plus a sanitized PDF agenda | Filtered schedule downloads with timezone-aware times |
| `07-google.png` | Your successfully synced fictional event and Planora result | Actual one-way Google Calendar synchronization; capture only after live verification |
| `08-reminders.png` | Saved reminder settings and an observed OS alert if permitted | Explicit permission and open-page reminder delivery |
| `09-administration.png` | Admin metadata/defaults with fictional test account | Protected account administration and shared defaults |
| `10-mobile.png` | Phone viewport showing usable task/settings workflow | Responsive interface and form-based editing |

Never include verification/reset link tokens, `.env`, developer network panels containing cookies, provider credentials, real private task notes, or other people's accounts. Add verified screenshots to your academic submission using its required template. Do not label a staged UI or test-double notification as a real external-delivery screenshot.
